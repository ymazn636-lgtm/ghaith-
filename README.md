# VpnApp — تطبيق أندرويد يتصل بخادم WireGuard

## ما هذا المشروع؟
هيكل مشروع أندرويد (Kotlin) جاهز يستخدم مكتبة WireGuard الرسمية للاتصال
بخادم VPN، مع بانر إعلانات AdMob في الأسفل. **هذا ليس تطبيقاً يعمل فوراً** —
هناك 3 أشياء يجب عليك ملؤها بنفسك قبل أن يتصل بأي شيء:

## 1. معلومات خادم WireGuard
عدّل `SERVER_CONFIG` داخل الملف:
`app/src/main/java/com/example/vpnapp/MainActivity.kt`

ضع فيه:
- `PrivateKey` الخاص بجهازك (يُنشأ عادة عند إضافة "peer" جديد على الخادم)
- `PublicKey` الخاص بالخادم
- `Endpoint` عنوان IP أو نطاق الخادم + المنفذ (عادة 51820)

إن لم يكن لديك خادم WireGuard بعد، يمكنك:
- استئجار VPS (مثل DigitalOcean / Hetzner) وتثبيت WireGuard عليه يدوياً، أو
- استخدام سكربت جاهز مثل `wireguard-install` لإعداده تلقائياً على أوبنتو/دبيان

## 2. AdMob App ID
في `app/src/main/AndroidManifest.xml` استبدل:
```
ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY
```
بمعرّف تطبيقك من لوحة تحكم AdMob (Apps → App settings → App ID).

## 3. AdMob Ad Unit ID (معرّف وحدة الإعلان)
في `app/src/main/res/values/strings.xml` استبدل قيمة
`admob_banner_ad_unit_id` (حالياً معرّف اختبار من جوجل) بمعرّف
وحدة الإعلان البانر الحقيقي الخاص بك من AdMob.

## كيفية البناء من الموبايل فقط (بدون حاسوب)
هذا المشروع يحتوي على ملف `.github/workflows/build.yml` يجعل GitHub
تبني ملف APK جاهز للتثبيت تلقائياً في السحابة. الخطوات من هاتفك:

1. أنشئ حساب مجاني على github.com (يمكن من متصفح الهاتف)
2. من تطبيق GitHub أو موقعه: أنشئ مستودع (Repository) جديد باسم مثلاً `VpnApp`
3. اختر **Upload files** وارفع كل محتويات هذا المجلد المضغوط بعد فك ضغطه
   (يمكن فك الضغط بأي تطبيق "فك ضغط ZIP" على الأندرويد ثم رفع الملفات
   من تطبيق الملفات، أو رفع نفس ملف ZIP إذا كان GitHub يدعم ذلك في واجهة الرفع)
4. عدّل الثلاث نقاط المذكورة أعلاه (بيانات الخادم، AdMob) — يمكنك تعديل
   الملفات مباشرة من متصفح GitHub بالضغط على أيقونة القلم ✏️ بجانب كل ملف
5. بعد الحفظ (Commit)، اذهب لتبويب **Actions** في المستودع — ستجد أن
   البناء بدأ تلقائياً
6. عند انتهاء البناء (علامة ✅ خضراء)، افتح التشغيلة (run) ثم انزل إلى
   **Artifacts** واضغط لتحميل `app-debug-apk` — هذا ملف APK جاهز للتثبيت
7. حمّل الـ APK على هاتفك وثبّته (قد تحتاج للسماح بـ "التثبيت من مصادر غير معروفة")

> ملاحظة: هذا يبني نسخة "debug" غير موقّعة رسمياً — تصلح للتجربة الشخصية،
> لكن لنشرها على متجر Google Play تحتاج لاحقاً توقيعها بمفتاح إصدار (release key).

## ملاحظات مهمة
- هذا مثال أساسي (اتصال/قطع فقط) وليس تطبيق إنتاج كامل — لا يوجد فيه
  حفظ إعدادات متعددة، أو اختيار سيرفرات، أو معالجة أخطاء متقدمة.
- تشغيل خدمة VPN يتطلب موافقة صريحة من المستخدم عبر نافذة نظام أندرويد
  (هذا مطبّق تلقائياً في الكود عبر `VpnService.prepare`).
- إن كان خادمك يستخدم OpenVPN بدلاً من WireGuard، الكود يحتاج تعديلاً
  لاستخدام مكتبة OpenVPN بدلاً من ذلك — أخبرني إن كانت هذه حالتك.
